1. Konfigurasi API

Key disimpan di localStorage browser ini. Untuk prototype lokal boleh, tetapi jangan gunakan cara ini untuk aplikasi produksi karena key dapat dilihat dari browser.

2. Tentukan lokasi pencarian

Gunakan lokasi perangkat saat ini. Browser akan meminta izin akses lokasi.

Tekan Enter atau klik Cari lokasi. Pilih salah satu hasil yang sesuai jika muncul beberapa pilihan.

Preview peta bersifat tampilan saja, bukan peta interaktif.
